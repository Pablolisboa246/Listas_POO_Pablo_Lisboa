Este repositório reúne os códigos desenvolvidos para as listas de exercícios da disciplina de Programação Orientada a Objetos, incluindo as três questões apresentadas em vídeo, conforme as orientações da atividade.

## Objetivo da lista

Desenvolver soluções em Python para os problemas propostos nas listas de exercícios, aplicando os conteúdos estudados na disciplina e exercitando a interpretação dos enunciados, a escolha das estruturas adequadas a cada problema e a construção de programas funcionais.

## Conteúdos trabalhados

**Lista 01 — Fundamentos de programação e estruturas condicionais**
Variáveis e tipos de dados, entrada e saída com `input()` e `print()`, operadores aritméticos, relacionais e lógicos, e estruturas condicionais `if`, `elif` e `else`.

**Lista 02 — Estruturas de repetição, funções e coleções**
Laços `for` e `while`, listas, dicionários, dicionários aninhados, criação de funções com parâmetros e retorno, docstrings e tratamento de exceções com `try` e `except`.

**Lista 03 — Estruturas de dados, arquivos, modularização e POO**
Laços aninhados, listas e dicionários compostos, leitura e gravação de arquivos, modularização em funções e conceitos de Programação Orientada a Objetos.

## Orientações para execução dos códigos

É necessário ter o Python 3 instalado. Nenhuma biblioteca externa é utilizada — todos os programas usam apenas recursos da própria linguagem.

Pelo terminal, a partir da raiz do repositório:

```bash
python lista_01/lista01_questao_01.py
```

Ou, pelo VS Code, abra o arquivo desejado e execute com **Run Python File**.

Os programas são interativos e solicitam os dados pelo teclado durante a execução. As questões que gravam arquivos criam esses arquivos no mesmo diretório em que o programa for executado.
